Assistenza

Questa è la pagina di assistenza di GiSquare Circuiti, sia del programma da installare sia della versione web GiSquare Circuiti Web, che si usa nel browser e si installa anche dal Google Workspace Marketplace.

Come chiedere aiuto

  • Email: scrivi a gisquare.circuiti@gmail.com. L’assistenza è gratuita e risponde direttamente l’autore, di solito entro qualche giorno lavorativo.
  • Segnalazioni pubbliche: puoi aprire una richiesta nella pagina Issues del progetto su GitHub (serve un account GitHub).

Per aiutarci a capire il problema indica:

  • se usi il programma installato (con la versione, che trovi nel pulsante Info) oppure la versione web;
  • il sistema e il dispositivo (per esempio Windows 11, Chromebook, Mac) e il browser;
  • che cosa stavi facendo e che cosa è successo, con una schermata se possibile;
  • se serve, il file del circuito (.gsq).

Non inviare dati personali degli studenti: prima di allegare schermate o file controlla che non contengano nomi, classi o altri dati. Come trattiamo i messaggi è spiegato nell’informativa sulla privacy.

Problemi frequenti

La versione web non si apre o mostra una versione vecchia

Ricarica la pagina con Ctrl+F5 (su Mac Cmd+Maiusc+R). Se non basta, cancella i dati del sito gisquarecircuiti.github.io dalle impostazioni del browser e riapri la versione web. Serve un browser aggiornato (Chrome, Edge, Firefox o Safari recenti).

Funziona senza Internet?

Sì: dopo la prima apertura il browser conserva una copia del programma. Per averla come app separata usa Installa GiSquare Circuiti Web dal menu del browser.

Il file del circuito non si salva o non si apre

La versione web salva i circuiti come file .gsq nella cartella che scegli, oppure nei Download. Sui Chromebook della scuola controlla che i download non siano bloccati dalle regole dell’istituto. I file .gsq si aprono sia nella versione web sia nel programma installato.

Gli sketch Arduino nella versione web

Nella versione web gli sketch non si compilano: si usano gli esempi già pronti oppure si carica un file .hex compilato con Arduino IDE. Il programma installato invece compila gli sketch direttamente.

Ho perso il circuito che stavo modificando

Riapri GiSquare Circuiti sullo stesso dispositivo: se c’è una copia di sicurezza del circuito non salvato, compare una barra che propone di recuperarla.

Windows mostra «Windows ha protetto il PC»

Il programma non è firmato digitalmente: scegli Ulteriori informazioni → Esegui comunque. Su Mac, al primo avvio: Impostazioni di Sistema → Privacy e sicurezza → Apri comunque.

Per gli amministratori Google Workspace

GiSquare Circuiti Web si può installare per tutta la scuola dal Google Workspace Marketplace. L’app si apre dal sito ufficiale e lavora nel browser: non legge Gmail, Drive o altri dati dell’account. All’installazione Google chiede solo i permessi di base per l’accesso (indirizzo email e profilo), che l’app non legge e non conserva. I passaggi sono spiegati nella guida per Chromebook e amministratori Google.
