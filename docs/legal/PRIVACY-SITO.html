Privacy del sito

Ultimo aggiornamento: 10 novembre 2026

Questa pagina riguarda il sito informativo di GiSquare Circuiti. L’informativa Privacy del programma riguarda invece il software installato.

Dati e funzioni del sito

Il sito è statico e non include moduli di contatto, account, strumenti di analisi del traffico, pubblicità, font remoti o servizi di tracciamento inseriti dall’autore. Il codice del sito non imposta né legge cookie e non usa archiviazione locale del browser.

Hosting GitHub Pages

Il sito è ospitato da GitHub Pages. GitHub dichiara che registra e conserva gli indirizzi IP dei visitatori per finalità di sicurezza. GitHub tratta inoltre i dati secondo le proprie informative e tecnologie, che possono dipendere dall’interazione con i suoi servizi.

Consulta la documentazione GitHub Pages, l’informativa privacy di GitHub e la pagina GitHub Cookies.

Collegamenti esterni

Se apri GitHub Releases, il repository o altri collegamenti esterni, la navigazione prosegue sui servizi dei rispettivi gestori e si applicano le loro informative.
