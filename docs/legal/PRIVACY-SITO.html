Privacy del sito

Ultimo aggiornamento: 23 novembre 2026

Questa pagina riguarda il sito informativo di GiSquare Circuiti. L’informativa Privacy del programma riguarda invece il software installato e la versione web.

Dati e funzioni del sito

Il sito è statico e non include moduli di contatto, account, strumenti di analisi del traffico, pubblicità, font remoti o servizi di tracciamento inseriti dall’autore. Il codice del sito non imposta né legge cookie. Le pagine informative non usano l’archiviazione locale del browser; la versione web la usa solo come descritto qui sotto.

Versione web

La versione web del programma (cartella app/ del sito) lavora interamente nel tuo browser. Usa l’archivio locale del browser solo per ricordare l’accettazione della licenza d’uso, i modelli di componenti che importi e le preferenze dell’interfaccia (per esempio il tema, il formato del foglio e il nome e la classe dell’ultima relazione); il browser conserva inoltre una copia dei file del programma (circa 20 MB) per aprirlo più in fretta e senza connessione, anche quando la installi come app. Sono strumenti tecnici necessari alle funzioni che chiedi: non servono a riconoscerti, restano sul tuo dispositivo e si cancellano eliminando i dati del sito dalle impostazioni del browser. I circuiti non vengono inviati all’autore né ad altri. I dettagli sono nell’informativa del programma.

Hosting GitHub Pages

Il sito è ospitato da GitHub Pages. GitHub dichiara che registra e conserva gli indirizzi IP dei visitatori per finalità di sicurezza. GitHub tratta inoltre i dati secondo le proprie informative e tecnologie, che possono dipendere dall’interazione con i suoi servizi.

Consulta la documentazione GitHub Pages, l’informativa privacy di GitHub e la pagina GitHub Cookies.

Collegamenti esterni

Se apri GitHub Releases, i video su YouTube, il repository o altri collegamenti esterni, la navigazione prosegue sui servizi dei rispettivi gestori e si applicano le loro informative. Il collegamento email apre il programma di posta scelto da te; i dati che decidi di inviare saranno trattati per rispondere alla richiesta.
